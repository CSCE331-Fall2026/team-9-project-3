# Menu pictures

`items/*.jpg` are official Panda Express product / marketing photos used for the customer Browse grid (#26).

Sources:
- `PandaExpressWebsite` S3 product detail photos (`pdp_*.jpg`)
- [pandaexpress.ca/our-food](https://www.pandaexpress.ca/our-food)
