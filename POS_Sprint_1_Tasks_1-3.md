# POS System — Sprint 1 User Stories (Tasks 1–3)

**Sprint:** Sprint 1  
**Status:** To Do  
**Story points:** Proposed estimates; confirm with your team during planning poker.

## Task 1: User Login

**User Story:** As an employee, I want to log in to the POS system so that I can access authorized features.

### Acceptance Criteria
- [ ] Given valid employee credentials, when I log in, then I can access the POS interface.
- [ ] Given invalid credentials, when I try to log in, then an error message appears.
- [ ] A successful login identifies the active employee.

**Story Points:** 3

## Task 2: View Menu

**User Story:** As a cashier, I want to view the menu so that I can find items and their prices.

### Acceptance Criteria
- [ ] The menu displays available items with names and prices.
- [ ] Each displayed item has a readable description.
- [ ] The cashier can view the menu without modifying menu data.

**Story Points:** 2

## Task 3: Create Order

**User Story:** As a cashier, I want to add menu items to a new order so that I can prepare a customer checkout.

### Acceptance Criteria
- [ ] A cashier can start an empty order.
- [ ] A cashier can add one or more menu items to that order.
- [ ] The order shows each selected item and its subtotal before tax.

**Story Points:** 5
