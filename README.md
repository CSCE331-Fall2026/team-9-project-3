# POS System — Sprint 1 Planning Poker

This repository content documents an **example** initial sprint backlog for a Point of Sale (POS) system. These are proposed estimates, **not** votes or consensus from an actual planning-poker session.

## Stories

| Story | Proposed Points |
|---|---:|
| User Login | 3 |
| View Menu | 2 |
| Create Order | 5 |
| Modify Order | 3 |
| Calculate Total | 3 |
| **Total** | **16** |

Each story and its acceptance criteria are in `issues/`. A spreadsheet-friendly version is in `sprint1_issues.csv`.

## How to add these to GitHub Projects

1. Upload these files to a GitHub repository (GitHub's web uploader accepts files; unzip before uploading).
2. Open your repository's **Issues** tab and create an issue for each story, copying its corresponding `.md` file content.
3. Open or create your **GitHub Project** and add the five issues.
4. Add a custom **Story Points** number field and set its values after your team completes planning poker.
5. Set an **Iteration** field to Sprint 1 if your project has one.
6. Submit the actual **GitHub Projects URL** in the class assignment.

**Note:** Uploading a ZIP or CSV to a repository alone does **not** create GitHub Issues or Project items. GitHub Projects must be populated separately. The CSV is a portable reference and does not imply native CSV import support in GitHub Projects.
